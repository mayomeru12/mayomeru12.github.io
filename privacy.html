butler-bot 개인정보처리방침

시행일: 2026년 10월 12일

1. 누가 사용하나요

butler-bot은 만든 사람 본인 한 명만 사용하는 개인용 프로그램입니다. 다른 사용자를 받지 않습니다.

2. 어떤 Google 데이터에 접근하나요

  • Google 캘린더: 본인의 일정을 읽고, 본인이 요청할 때 일정을 추가·수정·삭제합니다.
  • Gmail: 본인의 메일을 읽기 전용으로 읽어 요약합니다. 메일을 보내거나 지우지 않습니다.

3. 데이터를 어떻게 쓰고 보관하나요

  • 가져온 데이터는 본인에게 일정·메일을 알려 주는 데에만 씁니다.
  • 답장을 만들기 위해 필요한 내용이 AI 모델(Google Gemini API)에 전달될 수 있습니다.
  • 대화 기록과 요약은 본인이 관리하는 서버와 컴퓨터에만 저장합니다.
  • 데이터를 판매하거나 광고에 쓰거나 다른 사람과 공유하지 않습니다.

4. Google API 서비스 사용자 데이터 정책

butler-bot이 Google API로 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 접근 권한 해제

본인은 언제든지 Google 계정의 서드파티 액세스에서 butler-bot의 접근 권한을 해제할 수 있습니다.
